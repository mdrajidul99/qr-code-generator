What is a QR Code?

A QR (Quick Response) code is a two-dimensional barcode that stores information such as a URL, plain text, Wi-Fi credentials, or a contact card. Modern smartphone cameras can scan a QR code and act on its contents instantly.

How to Create a Custom QR Code

  1. Choose the QR code type — URL, Text, Wi-Fi, Email, Phone, SMS, Contact, or Location.
  2. Fill in the required fields.
  3. Open the Customize QR Code section to pick your colors, size, error correction level, style, and quiet zone.
  4. Click Create QR Code to generate it instantly.
  5. Download it as PNG, JPG, or SVG, or copy it to your clipboard.

QR Code Types You Can Create

  • URL / Website — open any web page.
  • Text — store a plain text message.
  • Wi-Fi — connect to a network without typing the password.
  • Email — pre-fill the recipient, subject, and message.

  • SMS — pre-fill a text message.
  • Contact / vCard — save name, phone, email, and address.
  • Location — open a map at specific coordinates.
